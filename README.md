# no-mas-grupos-random
DataSquad crea perfiles donde destacas tus habilidades dominantes y publicas la destreza técnica que le falta al equipo. El algoritmo hace match con el estudiante ideal. Al final, el sistema de calificación de compañeros evalúa el compromiso real de cada uno, asegurando el proyecto y filtrando a los clásicos estudiantes fantasma.
